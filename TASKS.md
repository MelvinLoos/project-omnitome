## Milestone 1: Database & Data Seeding

- [x] **Task 1.1:** `[Done]` **Local Supabase Setup:** 
  - Run `npx supabase init` and `npx supabase start` in the terminal.
  - Enable `pgvector` by ensuring it is part of your initial database configuration or first migration.
    
- [x] **Task 1.2:** `[Done]` **Schema - Monsters:** 
  - Create a migration file via `npx supabase migration new create_monsters`.
  - Write SQL to create the `monsters` table: `id` (UUID, primary key), `slug` (text), `name` (text), `cr` (text), `type` (text), `alignment` (text), and `raw_stats` (JSONB).
    
- [x] **Task 1.3:** `[Done]` **Schema - Community Content:** 
  - Create a migration via `npx supabase migration new create_community_content`.
  - Write SQL to create `community_content`: `id` (UUID, pk), `category` (text), `content` (text), `upvotes` (integer, default 0).
    
- [x] **Task 1.4:** `[Done]` **Ingest Script:** 
  - Create `scripts/ingest-open5e.mjs`. 
  - Use native `fetch` to GET `https://api.open5e.com/v1/monsters/`. 
  - Import `@supabase/supabase-js`, connect to the local Supabase instance, loop through the API results, and `insert` them into the `monsters` table.
    
- [x] **Task 1.5:** `[Done]` **Seed Script:** 
  - Create `scripts/seed-community-content.mjs`. 
  - Connect to local Supabase. Insert a hardcoded array of 5 sample adventure hooks and 5 sample stakes into the `community_content` table.
